# Scriptureware
A simple application to assist with Scripture memorization. Starting with a C++ CLI interface and the book of 1 Peter.

### Functionality

The functionality and intended user experience for this application are outlined [here](Documentation/functional_description.md "Functional Description"). This document reflects the overall design goals for each phase of the project and is laid out in sections in order to set concrete objectives while leaving room for more advanced versions of the application.

### Implementation

The detailed implementation of the project is outlined [here](Documentation/implementation_description.md "Implementation Description"). The basic file and class structures are outlined, along with some basic specifications for components of the application.

## Scriptural Texts

The texts for this application are taken solely from the KJV due to copyright limitations. Text files were sourced [here](https://kjv-txt-files.sourceforge.io/).
